## 更新日志（适用于 Blockus 部分）

### 3.2.1

- 加入深板岩圆石砖的相关形状变种。
- 修复了硫黄系列方块、朱砂系列方块、凝灰岩系列方块、磨制幽匿、幽匿砖、青绿石（viridite）系列方块、雪砖、浮冰砖（原冰砖）、烈焰砖、烈焰灯笼、下界砖系列方块（含异色或烧焦变种）、树脂砖系列方块、铜凝灰岩（包括各氧化和涂蜡变种）、紫颂块、瓦片的栅栏门、压力板、按钮的放置和破坏音效与其基础方块不一致的问题。
- 对于 Minecraft 26.1 以上版本，跟随 Blockus 的更新，将冰砖的相关形状变种更名为浮冰砖的相关变种，其中，此前放置的冰砖楼梯、台阶会被替换为 Blockus 中的相关方块，冰砖其他形状变种会被更新为本模组中的更名后的方块，物品会相应替换或更新。
- 对于 Minecraft 26.1 以上版本，跟随 Blockus 的更新，加入了深板岩苔石、深板岩苔石砖、哭泣黑曜石砖、小型哭泣黑曜石砖、环纹哭泣黑曜石的形状变种。

### 3.2.0

- 适应新版本的扩展方块形状模组。
- 为 1.21.10 以下版本跟进了 3.1.5 中的更新，包括：
    - 粗竹、青苔木板、白色橡木等相关方块的各形状变种加入至以 `wooden` 开头的形状标签。
    - `mineable/pickaxe` 方块标签加入繁星块相关方块，移除烈焰灯笼相关方块。
    - 修复部分的以 `wooden` 或 `log` 开头的形状标签只有方块标签、没有物品标签的问题。
    - 跟进 Blockus 更新，磨制末地石可切石为原版的末地石砖的各变种。
    - 石头可以切石为石瓦的各形状变种。
- 修复了在原版加入雕纹凝灰岩之前的本模组的雕纹凝灰岩相关方块没有 `mineable/pickaxe` 标签问题。
- 移除了粗糙砂岩、粗糙红砂岩、粗糙灵魂砂岩变种的墙，因为其纹理与砂岩、红砂岩、灵魂砂岩的墙纹理完全相同。
    - 此前已存在的上述方块和物品会被转换。
    - 此更新将适用于所有 Minecraft 版本。
    - 实际上，原版的砂岩墙、红砂岩墙以及 Blockus 的灵魂砂岩墙的各面纹理均相同，理论上更加接近粗糙砂岩、粗糙红砂岩、粗糙灵魂砂岩。但由于原版已有，故本模组不再为三种粗糙砂岩方块设置墙。
    - **此前在模组的 3.0.5 版本中，许多方块的形状变种被删除，但这些移除仅限 Minecraft 1.21.3 以上版本。在此前的 Minecraft 版本中放置的这些方块，在世界更新到 1.21.3 以上版本中会自动替换。这些被移除的方块，在适用于 1.21.3 以前的当前版本模组中仍然存在，但未来也有可能会移除，届时也会自动替换。具体的方块移除与替换的列表，请参考 3.0.5 的更新日志。**
- 进一步修复了切制灵魂砂岩相关方块纹理错误的问题。此问题可能仅存在于部分 Minecraft 版本。
- 移除了硫黄瓦、人字形纹硫黄砖、朱砂瓦、人字形纹朱砂砖的按钮、栅栏和栅栏门。更新模组后，这些方块和物品会被自动替换为硫黄砖和朱砂砖的相关方块。
- 由于在 1.21.1 和 1.21.8 以上版本中，Blockus 更改了小型原木的名称，本模组现在会像 Blockus 模组那样，将旧的小型原木（杨木等新版木头除外）方块和物品的 ID 视为新的 ID 的别称，并自动转换。例如，其他版本中放置的 `extshape_blockus:oak_small_logs_stairs` 会被自动替换为 `extshape_blockus:small_oak_logs_stairs`。
- 加入了铜砖和铜凝灰岩的相关形状变种（如果还未加入的话），并且现在这些方块现在也可以通过与蜜脾合成来涂蜡。
- 修复了铜砖相关的切石的错误。由于在 Blockus 中，一个铜块可以切成 4 个铜砖，故本模组中铜块切成铜砖的相关形状变种的数量也是按 4 倍计算。切制铜块切成铜砖仍为 1:1 保持不变。
- 修复了不兼容适用于 1.21.4 的最新 Blockus 模组的问题。

### 3.1.6

### 3.1.6-beta.3

- 加入了水砖的相关方块。此方块曾经出现过模型错误问题，故未曾加入，现未发现此模型问题，故予以加入。
    - 水砖相关方块均加入 `#blockus:water_bricks` 方块标签。-

- 修复 26.2 中带釉陶瓦柱相关方块纹理缺失的问题。

### 3.1.4

- 由于新版本 Blockus 添加了磨制方块的墙，因此本模组不再加入这些方块。本模组会使用 Fabric API 中的 registry alias 功能，使其旧版名称（Extended Block Shapes - Blockus 中的方块）兼容新版（Blockus 中的方块），例如 `extshape_blockus:polished_purpur_wall` 将等价于 `blockus:polished_purpur_wall`。

> Extended Block Shapes 主模组的 3.0.4 版本也进行过一次方块名称变更，但当时使用的是 Minecraft 原版的 DataFixer 实现的，并且不适用于 1.21.3 之前的 Minecraft。未来也可能会改用 Fabric API 的 registry alias，并使这些变更应用于 1.21.3 之前的版本。
